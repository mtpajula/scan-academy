    Registration

    1. 📌 Scan 1 is already placed (reference frame). Label the targets it sees, then Set base scan. Only the network + the selected scan are shown — one at a time.
    2. 🔗 Join scans one by one: pick the next scan in the list (if the selected one is from a totally different location with no overlap, choose another!), drag its cloud until it matches the registered cloud ✔, then Register to network. A join needs enough shared surfaces — cloud-to-cloud (dashed line).
    3. 🏷 Targets must be named before a scan can be registered — the checklist above the button shows what's missing; the register button stays disabled until targets are labeled (⚠ in the target list, or click the pulsing target on the canvas).
    4. ❌ Tick “bad scan” for shaken scans — they cannot join the network.
    5. ✔ When every good scan is in the network, Finish registration.
